What is pprhub?

Git records every commit's parents. Papers record theirs too: the bibliography. pprhub draws those links as a commit graph, so a lineage reads like git log --graph.

  • Commit: a paper.
  • Parents: its references. Only the most cited are drawn; the controls change how many.
  • Merge commit: a paper with several parents, which is nearly all of them.
  • Shared ancestor: a paper where lines join, because several papers in view cite it.
  • Spine: the straight line down the left, following each paper's most cited parent from the seed.
  • Fading line: the paper has references this view doesn't reach. The trail carries on.
  • Dead ID: a reference whose OpenAlex record returns 404. The work may exist elsewhere; the link is what's gone.

Everything shown is measured from a dated OpenAlex snapshot. Nothing here says whether a paper is right. It shows what a paper rests on, and where the trail stops.
